HLD 1: Local profile (single machine)

Developer workstation or small demo box (Windows 11 or Linux), started with `aspire run`. No Kubernetes; Docker is optional and used only for PostgreSQL. No domain name: UI at http://localhost:5173 (Vite), API and agents at http://localhost:5000; `--lan` adds https://<raw-ip>:5001 for LAN agents.

Glossary: terms in this diagram
HLD / local profile
High-level design: the main parts and their connections. This profile runs them on one developer machine.
localhost / raw IP / --lan
localhost means this same computer, so no domain name is needed. A raw IP is the computer's numeric network address; --lan lets other machines on the local network connect to it over an encrypted (HTTPS) link.
aspire run / Aspire dashboard
Aspire starts the local application parts together; its dashboard shows their logs, measurements and request traces.
Docker / WSL
Docker runs an application in an isolated container. Windows Subsystem for Linux (WSL) runs Linux on a Windows machine.
wf CLI / workflow.cs
The workflow command-line interface (CLI) publishes or runs a workflow; workflow.cs is its C# definition file.
React SPA / Vite / HMR
The browser interface is a single-page application (SPA). Vite serves it during development; hot module replacement (HMR) updates it without a full reload.
wf-host / API / engine
One local process combines the application programming interface (API), which accepts requests, and the engine, which schedules and tracks workflow runs.
wf-agent
A separate worker on the machine. It connects to the engine, reports its availability and manages task hosts; it does not run the workflow code itself or write to PostgreSQL.
Task host
A separate process started or reused by the agent to execute workflow tasks; it calls the sample services.
PostgreSQL / SQL / NOTIFY
PostgreSQL is the database for run state. SQL is its query language; NOTIFY is its signal that new work is ready.
Filesystem blobs / local secrets
Blobs are files such as reports and artifacts. Local secrets are passwords or keys kept outside workflow code.
%LOCALAPPDATA% / XDG data dir
Default places to store app data on Windows and Linux, respectively.
HTTP / HTTPS / REST / WebSocket / SignalR
HTTP carries web requests; HTTPS encrypts them, and REST names the API style. WebSocket keeps a two-way browser connection open; SignalR uses it to push live updates.
gRPC / UDS
gRPC carries messages between the engine and agent. Unix domain sockets (UDS) carry messages between local processes without opening a network port.
OTLP / telemetry
OpenTelemetry Protocol (OTLP) transports diagnostic logs, measurements and traces (a request's path through the system).
Sample services / Bond types / HTTP load
Test applications A and B use Bond-encoded data. HTTP load means tasks send test requests to those applications.
×1..N / arrows / dashed boxes
One or more copies; arrows show the direction of communication, while dashed boxes group parts on the same machine or in the same container.
