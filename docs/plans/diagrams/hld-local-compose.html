HLD 1b: Local prod-like (Docker + Caddy)

Optional `wf local up` (PPE only): production builds of every Linux component run in Docker behind a gateway Caddy on 127.2.6.7. The GrihaSetu edge Caddy serves https://ppe.kardia.sonapraneeth.in on the LAN with its mkcert umbrella certificate. The Windows agent stays native; `aspire run` remains the inner loop.

Glossary: terms in this diagram
HLD / prod-like / PPE
High-level design of a production-shaped local test setup. PPE is the named local test environment, not the deployed production system.
wf local up / aspire run
The first command starts release builds in Docker for integration testing; the second starts the quicker development setup.
Docker Compose / container / native
Compose starts a group of isolated containers. Native means a program runs directly on the host operating system instead.
Edge Caddy / gateway Caddy / GrihaSetu
Caddy is a web traffic router. The shared GrihaSetu edge accepts LAN traffic; the gateway inside Compose forwards it to the appropriate workflow service.
LAN / loopback / 127.2.6.7:80
LAN is the local network. Loopback means traffic stays on this computer; this address and port identify the private gateway, not a public internet address.
mkcert / certificate / TLS / HTTPS
mkcert creates locally trusted certificates. A certificate identifies the site; Transport Layer Security (TLS) encrypts web traffic, making HTTP into HTTPS.
wf CLI / workflow.cs
The workflow command-line interface (CLI) publishes and starts runs; workflow.cs is a C# workflow definition.
wf-api / REST / /api / /hubs
The application programming interface (API) accepts commands and serves data using web requests (REST). /api is for those requests; /hubs carries live updates.
SignalR / WebSocket
SignalR pushes live updates to browsers, usually over a long-lived two-way WebSocket connection.
wf-engine / leader / standby / PG lease
The engine schedules and tracks runs. One active copy is the leader; the other waits to take over. A timed record in PostgreSQL (PG) decides which copy leads.
PostgreSQL / SQL / NOTIFY
PostgreSQL is the database for run state. SQL is its query language; NOTIFY signals the engine when new commands arrive.
wf-agent (Windows / Linux)
A per-machine worker, not an AI agent or the engine. It registers, sends heartbeats, receives tasks over gRPC, manages task hosts and journals results until acknowledged. The Windows agent runs natively for Windows tasks; Linux agents run in containers for Linux tasks. Neither writes directly to the database.
Task host / UDS
A separate process that actually executes workflow tasks. It talks to its agent over a Unix domain socket (UDS), a private connection on the same machine.
gRPC / heartbeat
gRPC carries two-way messages between agents and the engine; a heartbeat is a periodic message saying the agent is still available.
Blob volume / named volume
Persistent file storage for uploads such as reports and artifacts; a named volume survives container restarts.
Sample services A / B / Bond types / HTTP load
Test applications that use Bond-encoded data; task hosts send them HTTP requests to exercise their behavior.
Aspire dashboard / OTLP
The dashboard shows diagnostics sent using OpenTelemetry Protocol (OTLP): logs, measurements and request traces.
×N / arrows / dashed boxes
Any number of copies; arrows show communication direction and dashed boxes group parts sharing a machine or Compose project.
